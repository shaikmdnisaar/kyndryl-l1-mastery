INC098231 • P1 CRITICAL Branch Office Core Switch Flapping & High CPU Loop
SLA: 15-min War Room Update

Client Symptom: Entire Dallas branch cannot access cloud apps. Pings have 80% loss. Core switch console reporting spanning-tree topology change storm.

L1 Triage Steps:
  1. Run show spanning-tree detail | include is the root|from to find which port is receiving frequent TCNs (Topology Change Notifications).
  2. Run show mac address-table count to see if MAC table is thrashing/flapping between ports.
  3. Identify the rogue switch or unmanaged hub on that port and execute shutdown on the offending access port.
[KYNDRYL L1 SERVICENOW WORKLOG TEMPLATE] Incident: INC098231 (P1 Spanning Tree Broadcast Storm) Root Cause: Unmanaged switch connected to Gi1/0/22 caused switching loop without BPDU Guard. Action Taken: Shut down interface Gi1/0/22. Spanning-tree stabilized on CORE-SW01. CPU returned to 4%. Status: Service restored. Recommended site technician inspect floor drop before port re-enablement.
INC098402 • P2 HIGH Finance VLAN 30 Workstations Assigning 169.254.x.x APIPA Addresses
SLA: 1-hour resolution

Client Symptom: 25 users in Finance department reporting yellow warning icon on Windows network status with zero LAN connectivity.

L1 Triage Steps:
  1. Run show ip interface vlan 30 on the Layer 3 core switch to verify SVI is Up/Up.
  2. Check if ip helper-address 10.100.1.50 is configured under interface Vlan30.
  3. Ping DHCP server IP from core switch. If reachable, check DHCP scope pool exhaustion on Windows/Infoblox server.
[KYNDRYL L1 SERVICENOW WORKLOG TEMPLATE] Incident: INC098402 (P2 DHCP Lease Failure) Root Cause: DHCP Helper address missing on newly provisioned VLAN 30 SVI following overnight maintenance. Action Taken: Configured 'ip helper-address 10.100.1.50' under SVI Vlan30. Tested client IP renewal (10.30.0.102/24 received). Status: Resolved. All 25 clients confirmed online.
INC098555 • P3 MEDIUM Executive Conference Room Port In Err-Disabled State
SLA: 4-hour resolution

Client Symptom: Wall jack Gi1/0/14 has no link light after conference video endpoint was moved.

L1 Triage Steps:
  1. Run show interface status err-disabled. Found reason: psecure-violation (Port Security).
  2. Run show port-security interface Gi1/0/14. Max allowed MACs: 1. Last violating MAC logged.
  3. Clear old MAC address: clear port-security dynamic interface Gi1/0/14 then bounce interface (shutdown / no shutdown).
[KYNDRYL L1 SERVICENOW WORKLOG TEMPLATE] Incident: INC098555 (P3 Port Security Err-Disable) Root Cause: Port Security violation triggered when new video codec MAC address was plugged into wall jack Gi1/0/14. Action Taken: Verified authorized hardware with local contact. Cleared sticky MAC table and un-shut interface. Status: Resolved. Link up at 1000Mbps Full Duplex.
