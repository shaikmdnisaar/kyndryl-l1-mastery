## 3. 🛠️ Lab Software Installation Package Guide

To build hands-on competency without spending money on physical hardware, install the following software package:

### 1. Cisco Packet Tracer (Official Free Simulator)
* **Cost:** Free from Cisco Networking Academy ([skillsforall.com](https://skillsforall.com/))
* **Version:** 8.2 or higher
* **Best For:** Phase 1 (CCNA foundations, VLANs, OSPF, ACLs, NAT, Wireless WLC).

### 2. Wireshark (Protocol Analyzer)
* **Cost:** Free & Open Source ([wireshark.org](https://www.wireshark.org/))
* **Key Packet Filters to Master:**
  * DNS queries: `dns`
  * DHCP DORA: `bootp` or `dhcp`
  * TCP Handshake: `tcp.flags.syn == 1`
  * HTTP / ARP: `http`, `arp`

### 3. EVE-NG Community / GNS3 (Full IOS Emulation)
* **Cost:** Free Community Editions (runs on VMware Workstation Player or VirtualBox)
* **Best For:** Phase 3 & 4 (CCNP ENCOR, ENARSI, BGP path manipulation, DMVPN Phase 3).

### 4. Python Network Automation Package
Set up your dedicated Python virtual environment for network automation:
```powershell
# Create dedicated virtual environment
python -m venv netauto_env

# Activate virtual environment
.\netauto_env\Scripts\activate

# Install essential network engineering packages
pip install netmiko napalm paramiko requests pyyaml netaddr
```

## 4. 🎯 The "Package Multiplier" Checklist (How to Secure Top-Bracket Offers)

When interviewing in Bengaluru for an L2 or L3 role (moving from ₹3.6 LPA to ₹6.5L or ₹10L+), hiring managers look for **proof of execution**, not just course completion certificates:

1. **Keep an Incident Logbook (Production Muscle):**
   * Document 5 real-world tickets you resolved at Kyndryl (e.g., VLAN mismatch, routing blackhole, DHCP pool exhaustion, interface flapping). Format as: **Issue ➔ Root Cause Analysis (RCA) ➔ Remediation ➔ Verification**.
2. **Bring Your Lab Topology Diagrams:**
   * Print or screenshare a high-resolution network diagram (Spine-Leaf, Core-Distribution-Access, or Dual-Hub DMVPN) designed by you. Walk the interviewer through your design choices.
3. **Master Subnetting Under Pressure:**
   * Be ready for surprise whiteboard/screen-share calculations during technical screens.
4. **Demonstrate Automation Awareness:**
   * Even for pure networking roles, showing a basic Python script that queries switch uptime via Netmiko sets you apart from 90% of other applicants.
